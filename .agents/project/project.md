# CamelotUI Project Brain

## Architecture
- Framework: Lit (Web Components)
- Build Tool: Vite
- Language: TypeScript
- Style: Multiple themes (Scifi, Material, Cupertino, Soft)

## Core Modules
- `src/components/base`: Base classes and reactive controllers.
- `src/components/theme`: Theme management system.
- `src/components/[style]`: Style-specific implementations.
