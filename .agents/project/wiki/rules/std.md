# Standards & Rules

Global development standards for CamelotUI.

## Design
- Follow Material 3, iOS, Soft UI, Sci-fi HUD specs.
- Use `CamelotBaseElement`.

## Workflow (PrecWF)
- Strict adherence to `.agents/rules/precision-workflow-guide.md`.

## Coding Convention
- **Rel Paths**: Mandatory in plans/docs.
- **Font Standardization**: Use `var(--cml-font-family)`.
- **Theme Inheritance**: CSS variable-based decentralized model.
