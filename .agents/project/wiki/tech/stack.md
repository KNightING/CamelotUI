# Technology Stack

Core stack for CamelotUI development.

## Frontend
- **Framework**: Lit (Web Components)
- **Logic**: TypeScript
- **Styling**: Vanilla CSS (via Lit `css`)
- **Tokens**: CSS Variables (`src/styles/tokens.css`)

## Entry Points
- `index.html`: Main canvas (minimal).
- `src/main.ts`: Unified logic entry.
